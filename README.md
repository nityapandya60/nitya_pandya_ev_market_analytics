# ⚡ EV Market Analytics — Tableau Dashboard, Story & Flask Web App

An end-to-end data analytics project: collect EV market data → store in a SQL database → analyse with SQL → visualise in **Tableau** (dashboard + story) → embed in a **Flask** web app.

## Business Problem
The EV industry is one of the fastest-growing automotive sectors. Strategy teams, consultants and researchers need to understand **which vehicle categories drive sales, who leads the market, which battery technologies dominate, where vehicles are built, and how satisfied customers are.**

### Personas
| Persona | Role | Key questions |
|---|---|---|
| Emily Johnson | EV Market Strategy Director | Which categories drive sales? Who leads? Which segments grow fastest? Satisfaction by segment? |
| David Chen | Automotive BI Manager | Market share, battery mix, manufacturing countries, ratings, competitive advantages |
| Dr. Sarah Williams | Sustainable Mobility Researcher | Battery comparison, range improvements, global production, adoption drivers |

## Tech Stack
Python (pandas) · SQLite (swappable with MySQL/PostgreSQL) · SQL · Tableau Desktop / Public · Flask · HTML/CSS

## Quick Start
```bash
git clone https://github.com/<your-username>/ev-market-analytics-tableau.git
cd ev-market-analytics-tableau
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python scripts/generate_dataset.py   # (optional) regenerates the sample data
python scripts/load_to_db.py         # builds data/ev_market.db
python scripts/run_queries.py        # runs the 11 analysis queries

python app/app.py                    # http://127.0.0.1:5000
```

## Dataset
`data/ev_market_data.csv` — 1,488 rows, 2019–2024. **Synthetic sample data** generated by `scripts/generate_dataset.py` with realistic relationships (e.g., range = capacity × efficiency × battery factor). Swap in a real dataset (Kaggle, government registries) using the same columns.

| Column | Description |
|---|---|
| sales_year, sales_region | Year and region of sales |
| manufacturer, model | Producer and model |
| category | Hatchback, Sedan, SUV, Bus, Truck, Two-Wheeler |
| battery_type | LFP, NMC, NCA, Sodium-Ion, Solid-State |
| battery_capacity_kwh, driving_range_km, fast_charge_minutes | Technical specs |
| price_usd | Average price |
| manufacturing_country | Where the manufacturer builds |
| annual_sales | Units sold |
| customer_rating | 1–5 |

## Included Tableau Workbook
- `tableau/Nitya Pandya.twbx` — packaged Tableau workbook with its embedded data extract.
- Download/clone the repository, then open this `.twbx` file in Tableau Desktop. The workbook and extract are included in the repository ZIP; GitHub itself previews files but does not run Tableau workbooks.

## Connecting Tableau
1. Open Tableau → **Connect → More… → SQLite** (install the SQLite ODBC driver) or simply connect to `data/ev_market_data.csv`. For MySQL: load `ev_market_data.csv` into a `ev_sales` table using `sql/schema.sql`, then **Connect → MySQL**.
2. Drag `ev_sales` (or the views in `sql/views.sql`) into the canvas.
3. Follow [`tableau/dashboard_design.md`](tableau/dashboard_design.md), [`tableau/calculated_fields.md`](tableau/calculated_fields.md) and [`tableau/story_scenes.md`](tableau/story_scenes.md).
4. Publish to **Tableau Public**, copy the share URLs, and set:
```bash
export TABLEAU_DASHBOARD_URL="https://public.tableau.com/views/<workbook>/<dashboard>"
export TABLEAU_STORY_URL="https://public.tableau.com/views/<workbook>/<story>"
python app/app.py
```
