# Demo Video Script (≈8–10 min)

1. **0:00 Intro** – problem, personas, goals.
2. **1:00 Data** – dataset columns, `generate_dataset.py`, loading into the DB (`load_to_db.py`).
3. **2:30 SQL** – walk through 3–4 queries (market share window function, CAGR, battery share).
4. **4:00 Tableau** – connection, calculated fields, 2–3 key worksheets.
5. **5:30 Dashboard** – filters, actions, device layouts.
6. **7:00 Story** – step through six scenes with insights.
7. **8:00 Flask app** – run `python app/app.py`, show embedded dashboard & story.
8. **9:00 Conclusion** – findings, recommendations per persona, future work.
